rc.10 带来插件 API 2——`renderData`（含结构化数据和缓存标签）、带参数和语言段的路由、限流分级、通过主题布局渲染的插件页面、内容保存与删除钩子、可编辑的记录面板以及挂在编辑器上的面板——站点级邮件设置，以及四项修复：打开第二篇内容时后台空白、打开内容即显示未保存、已删除的插件密钥仍显示为已设置、声明了脚本的主题绕过脚本检查。**更新日志的升级说明列出了现有站点、主题和插件需要做的事。**

**未在线上验证**，目前只有 Worker 测试和浏览器测试作为依据：

- 插件 API 2 整体。它由测试插件验证过，还没有真实插件在已部署站点上使用过 `renderData`、插件页面、记录面板或内容钩子。
- 用搬迁后的 Resend 密钥仍能发出邮件。搬迁本身已在线上看到，但没有通过它实际发过信。
- 按插件缓存标签清除时只影响带该标签的页面。
- 两个限流绑定各自计数。两者在测试账号上都部署成功，这只说明可以声明，不说明更多。Cloudflare 文档仍未写明 Free 套餐是否包含限流绑定。
- “已删除的插件密钥仍显示为已设置”这项修复，由端到端测试在真实浏览器里针对本地 Worker 验证。

rc.6 至 rc.10 均未重新采集 CPU 样本。下文 rc.5 性能数据仅为历史证据，不能作为 rc.10 跑分；`renderData` 和保存钩子会给当时已超出 10 ms 目标的请求增加开销。维护者接受已测 CPU 限制用于开源及 RC 试用；稳定版验收仍未完成。
