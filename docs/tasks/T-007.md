# T-007：D1 migration、持久化 codec 与 PublishedRepository

- 状态：Approved after T-005 acceptance; may run in parallel with T-006
- 阶段：Phase 2A
- 前置任务：T-001 至 T-005 已 `ACCEPTED`；T-006 不是本任务依赖

## 1. 目标

建立 `@mallok/cloudflare` 包、D1 schema/migrations、受控 `PublishedArtifact` 持久化 codec、metadata-only `PublishedRepository` 与 `AdminDocumentRepository`。只在本地 Cloudflare 测试环境中迁移、seed 和查询；不实现 Worker HTTP 路由、管理 handler、publish mutation 或真实账号操作。

## 3. 前置与冻结决策

`DATABASE.md` 与 `VERSIONING.md` 已冻结 persisted tuple、完整 DDL 和受控 codec。实现必须使用 core 内部的完整 row decoder（reference 名为 `decodePublishedRevisionV1`/窄 `decodeCompiledEntry` API），只接受完整 record；不得从包根暴露单独 body string → `SafeHtml`。

执行前确认这些 accepted reference 与实际 core export 设计一致；若只能通过任意 raw HTML factory 实现，返回 `BLOCKED` 并先走 ADR，不得自行改变文档。

## 4. D1 schema 与 migration

创建 `packages/cloudflare/migrations/0001_initial.sql`，逐字段实现 `DATABASE.md` 第 3 节完整 DDL：不可删除singleton的`mallok_state`、无slug的`documents`、含canonical `asset_refs_json`与SQL byte-length CHECK的`document_revisions`、`revision_tags`、当前slug唯一且受10,000 pointer trigger限制的`published_documents`、只存key hash的`idempotency_keys`、含durable `initial_deploy`/external-stage journal/candidate hashes/provider-clock epochs的`deployment_locks`、`mutation_guards`与lock trigger。不得退回早期`frontmatter_json`示例。

启用并测试foreign keys、CHECK/UNIQUE/composite FK、索引、revision/tag/pointer/fence不变量和固定version tuple。内容/审计timestamp由应用生成UTC ISO；只有deployment fence按accepted contract使用D1`unixepoch()`，避免CLI/Worker时钟域偏差。特别覆盖三个epoch为NULL/REAL/TEXT时CHECK失败、initial/non-initial baseline约束、external stage/target version约束。空库按序apply、重复apply no-op、失败migration回滚；0001成功必须原子留下`bootstrap-v1` barrier；没有自动down migration。

字段名、nullable 语义和 index 必须由 row mapper 测试锁定。schema 改动只能追加新 migration，不能修改已经验收的历史 migration。

## 5. 持久化 codec

- encoder 将 `CompiledEntry` + core media validator 的 `assetReferences` 转为 `DATABASE.md` 的显式列、canonical `tags_json/data_json/asset_refs_json/compile_options_json` 和连续 `revision_tags`，不保存双事实 frontmatter blob；
- decoder 严格按 `DATABASE.md` 第 5 节顺序验证 schema、SQLite value type、全部字段、canonical JSON、tag 投影、单一 persisted artifact/row-codec format、完整 profile tuple 和三个 hash；禁止 `SELECT *`；
- 任一 row/profile 不兼容使用 `PUBLISHED_REVISION_INCOMPATIBLE`；schema ledger 不兼容使用 `DATABASE_SCHEMA_INCOMPATIBLE`；诊断不含正文/HTML；
- 实现 source/body/row byte 重算、`payload_bytes` codec、SQL exact-byte CHECK、不可删除/不可缺失 state singleton、256 MiB ledger trigger 与 `D1_STORAGE_BUDGET_EXCEEDED` 映射；不得依赖字符长度或信任应用提交的 payload 数字；
- decoder 返回新的深度冻结快照，不冻结调用者 record；
- 旧/未知 tuple 默认拒绝公开恢复；请求时不得重编译 Markdown。

## 6. D1 repository

实现 core 的 exact contract：

- `listPublishedSummaries({ limit, offset, tag }, asOf)`：只选择 `PublishedSummary` 字段，禁止 source/body/data/template/asset refs；
- `findPublishedBySlug(slug, asOf)`；
- `listSitemapEntries(asOf)`：一次 prepared statement 只返回 `id/slug/contentPublishedAt/updatedAt` 的轻量行，稳定排序并 `LIMIT 10001`；第 10,001 行只用于触发 collection limit，不通过多次 offset 查询拼接 snapshot；
- limit 默认 20、范围 1..100；offset 默认 0；
- 只返回 published pointer 指向且内容发布时间已到的 revision；
- 无 `publishedAt` 的 published 内容立即可见，并排在所有显式日期之后，再按 slug 升序；
- 所有 SQL 使用 prepared statement 与 bind，不拼接 slug/tag/pagination；
- 无 tag 与有 tag 使用 `DATABASE.md` 两条固定 SQL；查询有明确上限，同一 statement 返回按 ordinal 的 `projected_tags_json` 并与 canonical `tags_json` 字节相同，缺/多/空洞/乱序全部 fail closed且无 N+1；累加包含两份受控 tag 字符串的 `summary_bytes`，整批超过 2,097,152 bytes 返回 `PUBLISHED_SUMMARY_TOO_LARGE`；
- sitemap 查询在单条 statement snapshot 内覆盖全部 current pointer，不读取 source/body/tags/data；future/unpublished 与集合越界测试必须包含并发 publish/unpublish fixture；
- 结果逐 row 经过 codec，不把数据库 body string 直接断言为 `SafeHtml`；
- malformed row 导致受控失败并记录 row/revision id，不记录正文；
- 实现 `AdminDocumentRepository.listDocuments/findDocument`：每个 item 由单个 statement 同时读取 document/current/latest，严格排序/filter/limit+1，不选择正文；用并发 fixture 证明不会跨多个查询拼成撕裂 view；
- 本任务使用 migration seed fixture，不提前实现 publish 领域逻辑。

## 8. 禁止改动

- core 根导出的任意 raw HTML 构造器
- 已接受的 compiler/hash/Theme/build/CLI 语义
- Worker HTTP router、管理 API、publish/unpublish、deploy/provision、GUI
- 真实 `database_id`、account id、token、`.dev.vars`
- `docs/**`、`.claude/**`、Git 历史或远程 D1

## 12. 停止条件

- 没有批准的持久化 codec/ADR，或必须公开任意 body string 构造 `SafeHtml`；
- migration 无 `schema_version` 或无法验证 persisted compiler/options；
- query 必须拼接用户值或执行无界扫描；
- summary query 必须读取正文，或管理 item 只能由多 statement 拼装；
- 测试工具尝试登录、联网或访问远程 D1；
- 需要修改已验收 migration 而不是新增 migration；
- 本地状态目录的所有权/清理边界不明确；
- Cloudflare 依赖没有精确版本与网络授权。
