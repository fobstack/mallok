## 4. Worker 路由

实现严格路由表：

- `GET|HEAD /`：D1 published 列表 → `renderHome`；
- `GET|HEAD /articles/<validated-slug>/`：D1 lookup → `articleTemplates[entry.template]`；
- `GET|HEAD /articles/<validated-slug>`：308 到 trailing-slash canonical；
- 不带 query 的 `GET|HEAD /index.html`：308 到 `/`，HEAD 无 body；带任何 query 先返回 400；
- `GET|HEAD /rss.xml`、`/sitemap.xml`：同一 published revision 集合；
- 不存在、draft、future、unpublished 与未知动态路径：一致的 theme 404；
- `/assets/*` 及其他构建静态资源交给 `env.ASSETS.fetch`，不得触发 D1；
- `/__mallok/api/v1/*` 为 T-009 预留并返回明确未实现/404，不得误走静态资产；
- 非 GET/HEAD 公共请求返回 405；无目录列表或任意 asset proxy。

URL 先检查 raw percent encoding，再只解码一次，slug 使用 core validator；malformed percent、encoded slash/backslash/NUL/control/dot segment 按 HTTP contract 返回 400；语法有效但非 canonical 的文章 path（其他 encoding、重复/额外 slash、非法 slug）返回主题 404。Worker-managed canonical dynamic route 只允许唯一合法 `__mallok_rev`，其他/重复参数与 redirect candidate 的任何 query 返回 400；未知 path 在 asset miss 后保持主题 404。asset-first 命中的静态资源 query 由平台处理且 D1 query=0。由 Worker 前置拒绝的请求其 redirect、D1 和显式 `env.ASSETS.fetch` 调用数为 0。

cloudflare assets 不生成 `/`、文章、`/404.html`、RSS、sitemap 的同名静态文件；404 由 Worker 使用同一主题渲染。generated Wrangler config snapshot 固定 `assets.html_handling: "none"`，只对 `/__mallok/api/*` 设置 `run_worker_first`；普通 assets asset-first，动态 route 因无同名文件进入 Worker；不得使用默认 HTML handling、全局 `run_worker_first: true` 或 deprecated `site`。

### 4.1 Cloudflare candidate 构建

- `mallok build --target cloudflare`复用T-004 BuildWriter，在同一受控stage中生成Worker bundle、assets和manifest，并以exclusive rename发布`.mallok/candidates/<inputHash>` immutable snapshot；`dist`只是由同一结果生成的preview视图。将本次candidate asset manifest以确定性数据内嵌进bundle；布局、manifest schema、摘要、input hash与`CloudflareCandidate`返回值以`docs/BUILD.md`、`docs/CLOUDFLARE.md`为唯一权威。
- candidate manifest 必须同时支持 T-010 的本地早期媒体诊断和 Worker 的服务端最终校验；两端消费同一生成结果，不得维护手写副本。
- 构建必须生成 Mallok-owned `dist/assets/_headers`，固定 `/*` 的 `Cache-Control: public, max-age=300` 与 `nosniff`；拒绝 public/theme 的 `/_headers` 冲突，并证明该控制文件不进入 build/asset/embedded manifest。
- 同一输入和工具链重复构建的 bundle、assets 与 embedded manifest 必须一致；时间戳、绝对路径、随机数、本机登录信息不得进入产物。
- cloudflare build manifest/candidate禁含`asOf`；显式`--as-of`用法失败，环境中的测试时钟不改变inputHash或任何candidate bytes。文章source/artifact hash不进入cloudflare inputHash，仅通过独立validate/publish链路处理。
- 已存在同inputHash snapshot只能在全inventory逐字节相同时返回`reused`；任一差异返回`BUILD_NONDETERMINISTIC_OUTPUT`且不能覆盖。snapshot发布后只读，后续build/dev对`dist`的原子替换不得修改它；current/previous/fence引用的snapshot不自动清理。
- build 阶段不得调用 Cloudflare API、D1 remote、upload、provision、migration 或 deploy，也不得读取真实 token。

## 5. 响应与缓存契约

- HTML `Content-Type: text/html; charset=utf-8`，feed 使用明确 XML type；
- HTML/asset 安全 headers 与 CSP 精确使用 `CLOUDFLARE.md` 第 8～9 节；必须 `await serializeSafeHtml`，让 core 用 Web Crypto 从受控 script-text contribution 计算 hash；输入是最终标签间精确 UTF-8 bytes，输出是带 padding 的标准 Base64 source；多个 source 去重稳定排序，不得扫描/二次序列化最终 HTML或退化为 `'unsafe-inline'`；
- 公开 ETag 按 `HTTP_API.md` 对最终未压缩 body bytes 计算 `W/"mallok-v1-<sha256>"` 弱 validator；article 另带不含敏感信息的 revision/artifact header；
- 正常公开 HTML/feed：`Cache-Control: public, max-age=0, s-maxage=60, must-revalidate`；
- 合法 `If-None-Match` 命中返回 304、无 body，并保留 ETag/cache header；
- 管理发布响应返回的 artifact hash 可用于文章 `?__mallok_rev=<artifact-hash>` cache-bust；参数必须为 64 位小写 hex，文章无 current pointer 时 404、pointer 存在但 artifact 不匹配时 409，匹配时 no-store且不改变 canonical；集合/feed route 只 cache-bust；
- 合法 cache-busted 公开读取必须通过注入的 D1 session port 证明使用 `first-primary`；普通公开读取可以走 replica，但单请求内不得混用 session/bookmark；
- canonical dynamic route 上缺值、非法或重复 cache-bust 参数按 HTTP reference 返回 400，D1 与显式 `env.ASSETS.fetch` 调用数为 0；静态资产和 unknown-after-miss 按 HTTP reference 的独立分支测试；
- 首页/RSS 只能调用 `listPublishedSummaries`，断言 D1 selected columns 不含 source/body/data/template/asset refs；单批 summary aggregate 超 2 MiB 返回 no-store 503，覆盖最大 100 行 fixture；
- 响应不包含数据库错误、SQL、绝对路径或堆栈；
- request id 由边界生成/接受受限 header，日志只含 route、status、duration、稳定 code 和 revision id。

本地测试验证 headers 与 Worker 逻辑；真实 CDN 的 60 秒行为留到 T-013，不能在本任务声称已验证。

## 6. 跨模式一致性

同一 fixture、site config、theme 和固定 `asOf`：

- 静态与 Worker 的 title、canonical、正文、导航、JSON-LD 归一化 DOM 一致；
- 只排除明确记录的 revision/request/cache metadata；
- 首页、RSS、sitemap 使用同一 revision 集合与排序；
- unpublish fixture 后所有聚合面不再引用对应 URL；
- theme 必须能通过 Node build 和真实 Worker bundler，不允许 Node builtin、环境、网络、系统时间或随机数。

## 12. 停止条件

- Worker bundle 包含 Node builtin 或 runtime-specific theme 分支；
- 静态与 Worker 必须复制渲染逻辑才能通过；
- 动态 route 会被 asset-first 规则绕过；
- cache-bust 需要关闭所有缓存或改变 canonical 内容；
- 本地工具请求登录/远程资源；
- DOM parity 只能通过忽略正文或大范围 snapshot 更新通过；
- 需要修改已验收 migration/codec 或使用真实 Cloudflare binding；
- cloudflare build 编排必须回到 command handler，或 use case 必须读取 argv/TTY/process 才能测试；
- `build --target cloudflare`需要由T-011补做bundling、asset manifest、assets或immutable candidate snapshot；这些职责必须在本任务关闭。
