# ADR-0001：静态与 Cloudflare 双运行模式

- 状态：Accepted for MVP
- 日期：2026-08-26

## 背景

用户同时需要纯静态输出和 D1 更新文章。纯静态 HTML 不执行数据库查询，数据库变化无法在不重新生成 HTML 的情况下自动反映。

## 决策

提供 `static` 和 `cloudflare` 两个显式 target。两者复用内容模型、Markdown 管道、路由计划和 Theme API，但分别在构建时和请求时渲染。

实现按阶段交付：static alpha 先验证 compiler/renderer，Cloudflare alpha 再验证发布投影；在跨模式一致性和真实部署门通过前，两者都不承诺稳定公共 API。

## 后果

- 优点：语义真实，静态站仍可部署到任意托管；动态站可立即读取 D1。
- 成本：必须维护两个适配器和一致性测试。
- 拒绝方案：用客户端请求 D1 API 填充“静态文章”。该方案会损害 SEO、无脚本访问、缓存和首屏稳定性，因此不作为默认模式。
