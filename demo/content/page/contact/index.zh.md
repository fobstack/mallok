一次有效询盘从材料形态、牌号、尺寸与数量开始。
图纸或规格书能帮助供应商更准确地理解项目。

## 这是演示页面

Northbound Titanium 是虚构企业。本只读站点不接收采购请求、图纸或个人联系信息，也不会发送任何消息。

在你自己部署的 Mallok 网站上，可以通过询盘插件接入 Turnstile 与 Resend。
接收真实询盘前，需要配置并验证这两项服务。

## 创建你的网站

[在 GitHub 获取 Mallok](https://github.com/fobstack/mallok)，或查看[部署指南](https://github.com/fobstack/mallok/blob/main/docs/CLI.md)。
