Northbound Titanium 是为了展示 **Atelier** 而创建的虚构企业。
Atelier 是 Mallok 面向工业与外贸网站的默认主题。

## 从材料到沟通

浏览棒材、板材与管材，比较示例规格，了解相关应用。
产品列表、详情页与材料分类使用同一份内容，保持一致的设计。

## 换成你的企业故事

真实供应商可以替换为自己的产品、工厂照片、检验文件与经过验证的资质。
这里的照片仅用于展示，示例规格与案例不构成实际报价、认证或真实客户项目记录。

## 使用 Mallok 构建

此中英文演示站使用 Mallok 的静态构建与内置 Atelier 主题。
完整部署的网站还可以使用内容后台与询盘插件；本只读演示站不收集询盘。

[在 GitHub 了解 Mallok](https://github.com/fobstack/mallok)。
